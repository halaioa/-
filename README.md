# -
由deepseek生成的刷课脚本
自动播放当前视频/音频，默认静音；
视频最高按平台播放器支持的 2× 播放；
视频结束后等待平台完成上报，再自动点下一节；
文档、图片课件按平台倒计时等待，计时结束自动下一节；
可选“PPT 加速”：跳过文档/PPT 的等待时间，默认关闭，属于实验性功能；
检测到弹题时暂停自动操作并提醒，不代答；
面板可拖动、可收起，设置会保存在浏览器里。
默认模式只做页面上的播放/点击自动化，不调用平台接口伪造进度，也不代答测验、作业、考试。 “PPT 加速”会跳过平台要求的学习等待时间，可能被平台判定异常，请自行决定是否开启。 平台规则和老师要求请自行确认，使用风险自负。
